# ECLIPSE — 잊혀진 균열

기획서(ECLIPSE 50레벨 액션RPG 통합게임기획서 v1)를 바탕으로 만든 2D 브라우저 액션 RPG입니다. PWA로 설치해 오프라인으로도 플레이할 수 있습니다.

## 실행

```bash
npm install
npm run serve      # 빌드 + 게임 서버 실행 → http://localhost:4173
```

Windows에서는 `ECLIPSE 실행.bat`을 더블클릭하면 빌드 후 서버가 켜지고 브라우저가 열립니다.
게임 서버(`server/index.mjs`)가 정적 파일, 계정/세이브 API, PvP WebSocket을 함께 제공합니다.
DB는 Node 내장 SQLite(`server/data/eclipse.db`)라 별도 설치가 필요 없습니다(Node 22.5+).

개발 모드: 터미널 1 `npm start`(서버), 터미널 2 `npm run dev` → http://localhost:5173 (API·소켓은 서버로 프록시).

### 외부 공개 (ngrok)

```bash
npm run serve
ngrok http 4173
```

ngrok이 주는 https 주소로 누구나 접속·회원가입·PvP를 할 수 있고, https라서 PWA 설치도 됩니다.

## 계정 · 저장 · PvP

- **회원가입/로그인**: 비밀번호는 scrypt 해시로 저장, 세션 토큰 30일, 계정당 캐릭터 3슬롯.
- **레벨 저장**: 진행이 바뀔 때마다(2초 디바운스) 서버에 업로드하고 창을 닫을 때도 전송합니다. 다른 기기에서 로그인해도 이어서 플레이할 수 있습니다.
- **게스트**: 로그인 없이도 플레이 가능(이 브라우저에만 저장, PvP 불가).
- **PvP 투기장**: 마을의 투기장 관리인 또는 ESC 메뉴 → 빠른 대전 / 방 코드. 1:1 실시간 2분, HP ×2 · 피해 ×0.7 · 포션 없음. ELO 레이팅과 랭킹.
  판정은 맞는 쪽 화면 기준이라 패링·대시 회피가 체감 그대로 통합니다. 서버가 능력치 상한과 메시지 속도는 검사하지만 완전한 서버 권위 판정은 아니어서, 본격적인 치트 방지는 추가 작업이 필요합니다.

## 앱 설치 (PWA)

`npm run serve`로 연 페이지(또는 ngrok 등 https 주소)에서
- 타이틀 화면의 **⬇ 앱으로 설치** 버튼, 또는
- 크롬/엣지 주소창 오른쪽 설치 아이콘

을 누르면 독립 창 앱으로 설치됩니다. 첫 실행 때 모든 리소스를 캐시하므로 이후에는 오프라인에서도 실행됩니다.
새 빌드를 배포하면 다음 실행 시 자동으로 업데이트됩니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 / 우클릭 | 약공격(L) / 강공격(H) — 좌클릭을 누르고 있으면 연타 |
| Space / Shift | 대시 (70~190ms 무적) |
| F | 패링 (120ms) — 성공 후 450ms 안에 L로 반격 |
| Q / E / R | 스킬 (Lv4 / Lv8) / 궁극기 (Lv20) |
| 1 | HP 포션 |
| G | 상호작용 |
| I / J / K / ESC / F1 | 가방 / 퀘스트 / 특성 / 메뉴(투기장·랭킹) / 도움말 |

게임패드(Xbox 배치)도 지원합니다.

## 구현 범위 (기획서 대응)

- 5직업(검사·격투가·마법사 + 궁수·창술사) — 스킬 계수, 콤보 커맨드(L-L-L, L-L-H, L-H-H, D-L-H, F-L-H), 특성 4단계
- 캐릭터 이름, 의상 12종 × 색상 8종
- 입력 버퍼 130ms, 콤보 유지 700ms, 대시 i-frame, 패링, 콤보 랭크 D~S, 상태이상(독·화상·빙결·출혈·가드파괴·그로기)
- 1~50레벨 경험치/성장 공식, 레벨 차 XP 보정
- 지형 시스템(강·늪·해자·빙하 호수·용암 강·공허 낭떠러지·다리·폐허 벽), 챕터마다 다른 필드·마을 배치, 방+복도형 던전(입장 시 문 잠김)
- 5챕터 · 일반 몬스터 30종(16가지 AI) · 엘리트 · 보스 10종(상태 머신, 페이즈, 가중치 선택, 공정성 규칙)
- 메인 퀘스트 50개, 사이드 퀘스트 20종, 던전 10개(전투·엘리트·퍼즐·함정 방), 체크포인트
- 장비 8슬롯·6등급·옵션·강화(+8)·재련·제작·분해, 유물 10종, 전설 천장, 보스 일일 보상 제한
- 엔딩 선택, 세이브 2개 로테이션, 세이브 내보내기/가져오기, 접근성 옵션(광과민 모드·흔들림 끄기·패턴명 표시)
