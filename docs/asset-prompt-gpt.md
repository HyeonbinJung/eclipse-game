# ECLIPSE 캐릭터 시트 제작 요청 (32×48 규격)

첨부한 확정 디자인(캐릭터 20명)을 그대로 따라, 아래 게임 엔진 규격에 **픽셀 단위로 정확히 맞는** 스프라이트 시트 PNG를 만들어 줘.
디자인(얼굴·의상·색)은 확정이니 새로 해석하거나 바꾸지 말고, 규격에 맞는 깨끗한 픽셀아트로 옮기는 작업만 해 줘.

## 0. 작업 방식 (중요)
- 이미지 생성 결과를 그대로 주지 말고, **Python(PIL)으로 최종 파일을 만들어 줘.** 그린 그림을 쓰는 경우에도 최근접 축소 → 팔레트 양자화 → 알파 이진화를 거쳐 정확한 픽셀 격자로 맞춰 줘.
- 디자인 이미지는 압축돼서 경계가 번져 있음. 번진 색·배경색(베이지)이 남지 않게 정리해 줘.
- 마지막에 "검증 체크리스트"를 Python으로 실행해서 결과를 보여 주고, 전부 통과한 파일만 줘.

## 1. 최종 결과물: `chars.png` 한 장
| 항목 | 값 |
|---|---|
| 파일 | `chars.png`, PNG RGBA |
| 시트 크기 | **정확히 320×96 픽셀** |
| 칸 크기 | **32×48 픽셀** (가로 32, 세로 48) |
| 배치 | 가로 10칸 × 세로 2줄. 칸 번호는 왼쪽 위 0번부터 오른쪽으로, 윗줄 0~9 / 아랫줄 10~19 |
| 배경 | 완전 투명 |
| 알파 | **0 또는 255만**. 반투명·안티에일리어싱·그라데이션·블러 금지 |
| 색 수 | 칸 하나당 최대 24색 (외곽선 포함) |
| 외곽선 | 1px 진한 색(권장 `#3f2631`)으로 실루엣 바깥을 감쌈 |

게임에서는 1.5배로 확대해 약 48×72px로 보임.

## 2. 칸 하나 안의 배치 규칙
- **발 위치:** 가장 아래 불투명 픽셀이 **46행**(0부터 셈)이 되게. 47행은 비워 둠. 엔진이 47행 경계를 발바닥 기준점으로 씀.
- **가로 중심:** 몸 중심이 15~16열 사이에 오게 좌우 가운데 정렬.
- **칸 밖으로 넘치지 않게.** 머리 장식(왕관, 잎, 귀)까지 전부 32×48 안에 들어와야 함. 위쪽 여백 0~2행.
- **시점:** 정면(약간의 3/4 정면 허용). 엔진이 좌우 반전으로 왼쪽을 보게 하니, 오른쪽을 기준으로 그림.
- **자세:** 대기(서 있는) 자세 한 장. 달리는 포즈인 19번(당근 궁수)도 서 있는 자세로 바꿔 줘. 걷기·공격 프레임은 필요 없음(엔진이 늘이고 기울여서 움직임을 만듦).
- **손 위치:** 엔진 무기는 오른손 위치인 **(23, 30)** 픽셀 근처에 겹쳐 그려짐. 무기를 들지 않은 캐릭터는 그 근처에 손이 오게 해 줘.

### 넣지 말아야 할 것
- 그림자(엔진이 발밑에 따로 그림), 배경, 바닥, 이펙트, 글자, 칸 테두리.

## 4. 함께 줄 것
1. `chars.png` (320×96 원본)
2. `preview.png`: `chars.png`를 **6배 최근접 확대**하고 칸 경계선과 칸 번호를 표시한 확인용 이미지
3. 각 칸에서 쓴 색 목록(HEX)

## 5. 검증 체크리스트 (Python으로 실행해서 결과 출력)
- [ ] 시트 크기가 정확히 (320, 96), 모드 RGBA
- [ ] 알파 값 집합이 {0, 255}의 부분집합
- [ ] 20칸 모두 불투명 픽셀이 있음
- [ ] 각 칸: 고유 색 수 ≤ 24
- [ ] 각 칸: 가장 아래 불투명 행 = 46, 47행은 전부 투명
- [ ] 각 칸: 불투명 영역 좌우 중심이 14~18 사이
- [ ] 각 칸: 불투명 픽셀이 칸 경계를 넘지 않음(옆 칸으로 번지지 않음)
- [ ] 베이지 배경색(대략 `#f0e2c8` 근처) 픽셀이 실루엣 가장자리에 남아 있지 않음

하나라도 실패하면 고친 뒤 다시 검증해서, 전부 통과한 결과만 줘.
