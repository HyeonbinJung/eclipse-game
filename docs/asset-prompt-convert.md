# 첨부 이미지 → chars.png 변환 요청

첨부한 이미지는 네가 만들어 준 캐릭터 디자인 20명이야. 이 이미지를 내 게임에 바로 넣을 수 있는 **`chars.png` 스프라이트 시트**로 변환해 줘.
디자인은 확정이니 얼굴·의상·색을 바꾸지 말고, 같은 캐릭터를 아래 규격의 깨끗한 픽셀아트로 옮겨 줘.

> 이 이미지를 처음 만들 때 쓴 **고해상도 원본**이 있으면 그걸 원본으로 써 줘. 첨부본은 2000×150 WebP라 캐릭터 하나가 약 70×130px이고 압축 때문에 경계가 번져 있어.

## 1단계: 캐릭터 잘라내기 (Python)
- 배경은 베이지 단색(대략 `#f0e2c8`)이야. 배경과 색 차이가 큰 픽셀을 전경으로 잡고, 세로로 빈 열을 기준으로 캐릭터를 나눠 줘.
- 첨부본(2000×150) 기준으로 확인한 캐릭터별 가로 범위야. 해상도가 다르면 비율로 환산해 줘.

## 2단계: 32×48 픽셀아트로 다시 그리기
단순히 축소만 하면 얼굴이 뭉개져. 축소한 결과를 밑그림으로 쓰고, 아래 규칙대로 **픽셀을 정리해서 다시 찍어** 줘.

1. 캐릭터마다 비율을 유지한 채 **최대 30×46** 안에 들어오게 축소해. 확대·축소에는 최근접(nearest) 또는 박스 필터만 써.
2. 색을 **칸당 최대 24색**으로 양자화해. 비슷한 색은 합치고, 원래 디자인의 대표 색(피부, 머리, 의상, 과일 색)은 꼭 남겨.
3. 알파를 0/255로 이진화하고, 가장자리에 남은 베이지·회색 번짐 픽셀은 지워.
4. 실루엣 바깥에 **1px 외곽선**(`#3f2631`)을 둘러. 외곽선 안쪽의 끊긴 부분도 메워.
5. **눈, 입, 머리 위 장식(왕관, 잎, 귀, 꼭지)** 은 1~2px라도 또렷하게 보이게 손으로 다듬어. 눈은 좌우 대칭으로.
6. 19번(당근 궁수)은 달리는 포즈라서 **서 있는 대기 자세**로 다시 그려. 활은 그대로 들고 있게.
7. 무기:
   - 9번(검), 12번(대검), 13번(마법 구슬), 19번(활)은 디자인에 있는 무기를 **그대로 포함**해 칸 안에 맞춰.
   - 나머지 16명은 무기를 그리지 말고, 오른손(칸 기준 약 (23, 30) 픽셀)을 비워 둬. 게임이 그 위치에 무기를 따로 그려.
8. 그림자, 배경, 바닥, 이펙트(13번의 빛 번짐 포함), 글자는 넣지 마.

## 3단계: 시트로 조립
| 항목 | 값 |
|---|---|
| 파일 | `chars.png`, PNG RGBA |
| 시트 크기 | **정확히 320×96** |
| 칸 | 32×48, 가로 10칸 × 세로 2줄. 윗줄 0~9, 아랫줄 10~19 (위 표 순서) |
| 발 위치 | 각 칸에서 가장 아래 불투명 행이 **46행**(0부터 셈). 47행은 비움 |
| 가로 위치 | 몸 중심이 15~16열 사이 |
| 위쪽 | 머리 장식까지 칸 안에. 옆 칸으로 넘치면 안 됨 |
| 방향 | 정면(약간의 3/4 허용). 게임이 좌우 반전으로 왼쪽을 처리 |

## 4단계: 검증 (Python으로 실행하고 결과 출력)
- [ ] 크기 (320, 96), 모드 RGBA
- [ ] 알파 값이 {0, 255}뿐
- [ ] 20칸 모두 불투명 픽셀이 있음
- [ ] 각 칸 고유 색 수 ≤ 24
- [ ] 각 칸 가장 아래 불투명 행 = 46, 47행은 전부 투명
- [ ] 각 칸 불투명 영역의 좌우 중심이 14~18
- [ ] 베이지 배경색과 비슷한 픽셀(RGB 거리 40 이내)이 실루엣 가장자리에 없음

하나라도 실패하면 고친 뒤 다시 검증해 줘.
